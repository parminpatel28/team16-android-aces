# Munchies Backend Server


## Background

This is the backend server for the Munchies Application. The server is written 
using Java `Spring Boot`. 

When setting this up I was using Intellij however you can keep it in Andriod Studio.

This project is using `Java 17` and `JDK 18`

## Setup

1. In project directory (`./backend`) run `./gradlew build`
2. To run the server execute `./gradlew bootRun` within the terminal
3. Make a Curl request using this command `curl http://localhost:8080` (it will throw a 404 but that is expected)
